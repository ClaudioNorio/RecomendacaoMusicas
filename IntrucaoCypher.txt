3) Procurar perfis para recomendar as músicas
Critérios para achar perfis similares de pessoas: curtem o mesmo gênero, compram o mesmo álbum e seguem o mesmo cantor. 
Escolhida uma pessoa aleatoriamente fazer recomendações de músicas para ela.
Ao encontrar perfis similares desta pessoa, retirar as músicas em comum. Mostrar apenas 20 músicas de recomendação.
MATCH (p)-[:CURTE]->(g:Genero)<-[:CURTE]-(outra)
WITH collect(g) AS generos
RETURN size(generos) AS generos_comuns 

Outra opção (sem usar size)

MATCH (p:Pessoa {nome:'Jean Oliveira'})
MATCH (outra:Pessoa)
WHERE p <> outra

OPTIONAL MATCH (p)-[:CURTE]->(g:Genero)<-[:CURTE]-(outra)
WITH p, outra, count(DISTINCT g) AS generos_comuns

OPTIONAL MATCH (p)-[:COMPRA]->(a:Album)<-[:COMPRA]-(outra)
WITH p, outra,
     generos_comuns,
     count(DISTINCT a) AS albuns_comuns

OPTIONAL MATCH (p)-[:SEGUE]->(c:Cantor)<-[:SEGUE]-(outra)
WITH p, outra,
     generos_comuns,
     albuns_comuns,
     count(DISTINCT c) AS cantores_comuns

WITH p,
     outra,
     generos_comuns + albuns_comuns + cantores_comuns AS score

WHERE score > 0

MATCH (outra)-[:OUVE]->(m:Musica)

WHERE NOT EXISTS {
    MATCH (p)-[:OUVE]->(m)
}

WITH m, outra, score

RETURN
m.nome AS musica_recomendada,
sum(score) AS relevancia
ORDER BY relevancia DESC, musica_recomendada
LIMIT 20
